# BLE Scanner add-on repository

Home Assistant add-on repository with **BLE Scanner**: an MQTT-based scanner for
discovering BLE devices through ESP32 BLE proxies, following the
[smartbed-mqtt](https://github.com/richardhopton/smartbed-mqtt) pattern.

Add this repository in Home Assistant under **Settings → Add-ons → Add-on Store → ⋮ → Repositories**:

```
https://github.com/bramboe/octo-mqtt-new
```

See [`ble_scanner/README.md`](ble_scanner/README.md) for configuration and details.
